Projeto de cadastro de usuários criado com Spring Boot e Java para minha melhor compreensão sobre os assuntos abaixo:

-- Cadastrar usuários em banco de dados e retorná-los para a requisição.
-- Criar, Mapear e Transformar Entidade do usuário em usuário DTO: deixar a entidade mais segura e retornar apenas os dados necessários, não expondo o cliente.
-- Criar controladores de Exceções e fazer com que dados sigilosos não sejam retornados por meio de uma White-label, requisição de rotas erradas ou até mesmo por meio de uma Exceção de Runtime.

Nesse projeto aprendi e apliquei essas técnicas acima, deixando o projeto mais sólido e seguro.
